# 降尺度模块:新纪录预测能否做到市县水平

## 先说结论

**能,但必须换一种问法。**

响应变量「某物种在某省首次被记录」是**行政绑定**的:一个物种在某县第一次出现,
可能在同省别处早已为人所知,那不是一条新的省级纪录。原始汇编(CBNR)只收录
**省级**首次记录,因此不存在同类型的县级事件集,不能把省级模型直接搬到县上。

可以做的是把预测拆成两段:

```
P(新纪录发生在县 c, 年 t)
  = P(该省该年发生一条新纪录)          第一段:已冻结的省级风险模型
  × P(落在县 c | 该省已发生, 年 t)      第二段:本模块新建的省内分配模型
```

两段都可估,乘起来就是县级预测。**结果是:第二段(县级分配)有扎实的样本外技能,
真正限制外推年限的是第一段(省级风险)的支撑域约束。**

## 一、省内分配模型

### 设计
条件 logit。每个事件自成一层,备择集 = 该事件所在省的**全部**市/县。
617 条发现年定年事件可配到与其省份一致的行政单元(657 条中的 94%)。

- 县级:2899 个单元,备择集 58,306 行,每事件备择数中位 **103**
- 市级:371 个单元,备择集 7,420 行,每事件备择数中位 **13**

### 协变量(全部在省内有变异)

| 变量 | 来源 | 说明 |
|---|---|---|
| 到该物种分布区的距离 | BirdLife BOTW_clean(466 种,374 个事件物种全覆盖) | 单元质心到分布区多边形的最短距离,质心在区内记 0 |
| 质心是否已在分布区内 | 同上 | 二元 |
| 累计观鸟努力 | GBIF/eBird,事件年**之前**的累计 checklist 数 | 单元级真实值,不用 `data/derived` 下由省级值分摊的 `n_visits`(已核实其省内唯一值恒为 1) |
| 单元面积 | 审图号底图 | 机械性:面积大更容易装下那条记录 |
| 年均温、年降水、海拔 | 50 km 格面积加权聚合 | |
| 保护地覆盖 | 保护区并集与单元求交 | |

### 系数(M3,县级 / 市级)

| 变量 | 县级 OR (95% CI) | 市级 OR (95% CI) |
|---|---|---|
| 到分布区距离(每 1 SD log km) | **0.238 (0.19–0.30)** | **0.177 (0.13–0.24)** |
| 质心已在分布区内 | **0.150 (0.08–0.29)** | **0.040 (0.02–0.10)** |
| 累计观鸟努力(每 1 SD) | 1.755 (1.63–1.89) | 1.862 (1.64–2.11) |
| 单元面积(每 1 SD log) | 1.805 (1.60–2.03) | 1.847 (1.56–2.19) |
| 年均温(每 1 SD) | 1.903 (1.27–2.84) | 2.231 (1.41–3.53) |
| 年降水(每 1 SD) | 1.457 (1.18–1.80) | 1.175 (0.90–1.54) |
| 保护地覆盖(每 1 SD) | 1.223 (1.15–1.30) | 1.029 (0.93–1.14) |
| 海拔(每 1 SD) | 1.172 (0.78–1.76) | 1.145 (0.75–1.76) |

**最强的预测变量是到该物种已知分布区的距离,不是观鸟努力。** 这一点重要:
它说明县级落点主要由生态学的「离分布区边缘有多近」决定,观测努力是第二位的。

「质心已在分布区内」的系数远小于 1 也符合定义——一条**新的**省级纪录,
按定义发生在这个物种尚未被记录的地方,因此更可能落在已知分布区之外或边缘。

### 模型阶梯(一致性指数)

| 阶梯 | 市级 | 县级 |
|---|---|---|
| M0 仅面积 | 0.635 | 0.642 |
| M1 + 累计观鸟努力 | 0.688 | 0.711 |
| M2 + 到分布区距离 | 0.745 | 0.756 |
| M3 + 环境 | 0.739 | **0.765** |

加入分布区距离带来的增量最大;环境变量在县级还有增量,在市级已饱和。

## 二、样本外技能:到底能不能预测

这是本模块的核心检验。**用 2002–2018 年拟合,预测 2019–2024 年**(219 / 218 个测试事件),
指标是「真实发生的那个单元在预测排名中的分位」——0.5 等于随机,越小越好。

### 市级(备择数中位 13)

| 方法 | 排名分位 | top-1 | top-3 |
|---|---|---|---|
| **M3 分配模型** | **0.348** | **30.1%** | **60.7%** |
| 基线:仅到分布区距离 | 0.397 | 25.6% | 55.3% |
| 基线:累计观鸟努力 | 0.396 | 23.7% | 47.0% |
| 基线:单元面积 | 0.477 | 13.2% | 35.2% |
| 基线:随机 | 0.559 | 13.2% | 29.2% |

### 县级(备择数中位 103)

| 方法 | 排名分位 | top-1 | 前 10% 命中 |
|---|---|---|---|
| **M3 分配模型** | **0.229** | **16.1%** | **45.4%** |
| 基线:累计观鸟努力 | 0.311 | 8.3% | 37.2% |
| 基线:仅到分布区距离 | 0.334 | 6.4% | 30.3% |
| 基线:单元面积 | 0.372 | 3.7% | 23.9% |
| 基线:随机 | 0.496 | 0.0% | 10.6% |

县级 top-1 命中 16.1%,而 103 个备择的随机期望约 1%——**约 17 倍**;
「真实县落在预测前 10% 之内」的比例是 45.4%,随机期望 10%。

### 留一省验证(空间外推)

把整个省从训练集中移除后再预测该省。县级 29 个省中 **27 个优于随机**,
中位排名分位 **0.248**;例外是重庆(0.531)与海南(0.571),两者都是
单元数少、地理特殊的省。市级 18 个省中 17 个优于随机(山东例外)。

## 三、县级落点面

对每个省,取截至 2024 年仍在风险集内的候选物种(7,662 个物种-省对,341 个物种),
计算每个候选物种在省内各县的分配概率,再对候选物种取等权平均,
得到「下一条省级新纪录落在各县的期望份额」。

## 四、外推边界:限制来自省级那一段

县级分配依赖当前的物种分布格局与观测格局,可以稳定外推;
但两段相乘之后,能推多远由**第一段**决定:

| 情景 | 2030 | 2050 | 2080 |
|---|---|---|---|
| SSP2-4.5 | 47.8% | 10.4% | 2.1% |
| SSP5-8.5 | 34.2% | 2.1% | 1.9% |

(落在拟合协变量范围内的物种-省组合比例)

因此:

- **近期(当前至 2030 年,SSP2-4.5)**:县级面可以作为监测布点与预警的操作性产品
- **2050 年及以后**:省级只剩约一成组合可外推,县级面继承这一限制,只能作情景演示

**做不到县级预测的原因不在县级这一段。** 把分辨率从省推到县,技能是增加的
(排名分位从随机的 0.5 降到 0.23);受限的是气候外推本身。

## 五、必须一并陈述的局限

1. **响应变量口径未变**:预测的是「省级首次记录落在哪个县」,不是「该物种在该县首次出现」。
   后者需要县级首次记录的汇编,本项目没有。
2. **分布区是静态的**:BirdLife 当代分布不随年份或情景变化。因此分配模型刻画的是
   「在当前分布格局下」的落点概率,分布区本身的推移未被建模。
3. **观测努力是静态外推的**:县级面用截至 2023 年的累计 checklist 数
   (观测层止于 2023)。若某县未来观鸟量激增,其份额会被低估。
4. **行政区划不追溯**:使用审图号底图的当期区划,不还原历史调整。
   底图中 2 个 PAC 重码(苏州两个城区、台湾一例)按编码融合处理。
5. **40 条事件被排除**:657 条中有 40 条的坐标落在其记录省份之外(多为近海、岛屿
   或坐标精度不足),不进入分配模型。
6. **坐标精度**:事件坐标量化至 2 位小数(约 1.1 km)。在县级尺度(中位面积约
   1500 km²)这一误差可以接受,但对面积极小的市辖区会有影响。
7. **重庆与海南留一省劣于随机**,说明该方法在单元数少、地形特殊的省份不稳健,
   不应在这些省份单独使用。
