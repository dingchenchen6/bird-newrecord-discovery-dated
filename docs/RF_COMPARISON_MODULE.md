# 随机森林 vs 机制模型:省级发生与市县级落点

## 一句话结论

**随机森林在内插时更强,在外推时更弱,而且它学到的主要是观测过程。**
这不是「谁更好」的问题——两族模型在回答不同的问题,而验证方案一换,排名就翻转。

---

## 一、省级:新纪录是否发生

数据:175,901 行,649 事件,**事件率 0.369%**。因为正例极稀,主指标用 **PR-AUC**,
AUC 会被海量真阴性抬高;同时报告 Brier 与校准斜率。

### 参与比较的五个模型

| 模型 | 说明 |
|---|---|
| 离散风险模型(边际) | 冻结主模型,只用固定效应 + offset 预测。新物种/新省份没有 BLUP,只能这样用 |
| 离散风险模型(条件) | 加上 BLUP,只在随机验证下可用 |
| 随机森林(同信息) | 特征 = 主模型的三个固定效应 + 报告完整度,与主模型信息量完全对等 |
| 随机森林(加结构) | 再加 年份、省份、迁徙类型——树模型表示随机效应结构的唯一方式 |
| 随机森林(类平衡) | 在「加结构」基础上做等量下采样,稀有事件的常规做法 |

### PR-AUC(主指标)

| 验证方案 | 风险模型(边际) | 风险模型(条件) | RF 同信息 | RF 加结构 | RF 类平衡 |
|---|---|---|---|---|---|
| 随机 5 折 | 0.0058 | **0.0110** | 0.0064 | 0.0085 | **0.0137** |
| 留物种 5 折 | 0.0054 | — | 0.0066 | 0.0085 | **0.0121** |
| 留省 5 折 | **0.0056** | — | 0.0041 | 0.0044 | 0.0053 |
| 时间前推 2019–2024 | **0.0098** | — | 0.0060 | 0.0070 | 0.0067 |

(事件率基线 0.00369,故 0.0137 相当于 3.7 倍提升,0.0041 相当于 1.1 倍)

**读法**:随机与留物种验证下随机森林领先约一倍;一换成**留省**或**时间前推**,
随机森林掉到基线附近,而机制模型基本不动甚至反超。

AUC 给出的排序在时间前推下与 PR-AUC **相反**(RF 0.605 vs 风险模型 0.524):
随机森林把整体次序排得略好,机制模型把真正的正例排得更靠前。在 0.369% 的事件率下,
后者才是有用的性质。这也是为什么必须以 PR-AUC 为主指标。

### 校准

| 模型 | 校准斜率(理想 = 1) | Brier |
|---|---|---|
| 离散风险模型 | 0.90 – 1.00 | 0.0037 |
| RF 同信息 | 0.03 – 0.08 | 0.0038 |
| RF 加结构 | 0.13 – 0.30 | 0.0038 |
| RF 类平衡 | 0.50 – 0.99 | **0.147 – 0.153** |

概率森林把风险压得极扁(斜率接近 0),类平衡森林斜率接近 1 但概率整体放大约 40 倍。
**机制模型的输出概率可以直接当年风险用,随机森林的不能**——它只能用来排序。

### 随机森林到底在学什么

置换重要性(加结构版,相对最大值):

| 变量 | 相对重要性 | 归属 |
|---|---|---|
| **年份** | 1.000 | 观测过程 |
| 调查努力 | 0.972 | 观测过程 |
| 累积变暖 | 0.894 | 生态过程 |
| 报告完整度 | 0.872 | 观测过程 |
| 年度气候变异 | 0.813 | 生态过程 |
| 省份 | 0.794 | 观测过程 |
| 迁徙类型 | 0.109 | 生态过程 |

**前四位有三个属于观测过程,首位是年份。** 树模型学到的主要是
「哪些年、哪些省容易出记录」——这正是本文主线所说的、必须与生态信号分开的那一部分。
它在内插时很有用(观测格局在训练与测试之间是连续的),在换省或换年份时立刻失效。

### 外推行为

固定努力于均值,把累积变暖从 −3 SD 推到 +10 SD(拟合范围 −3.0 至 3.3 SD):

- 随机森林在约 **2.9 SD** 处就返回边界叶值,此后**恒定在 6.7%**,不再变化
- cloglog 在对数风险尺度上线性外推,10 SD 处到 5.3%

两种行为都不被数据验证。但它们的性质不同:机制模型的外推是**可以被审查的假设**
(线性在对数风险尺度上),随机森林的饱和是**算法产物**,与生态学无关。
这也是本文对未来投影一律加支撑域掩膜的原因。

## 二、市县级:落点分配

分配任务是层内排序:给定该省发生了一条新纪录,哪个单元承接。
条件 logit 天然按层估计;随机森林只能把每个备择当独立样本打分再层内排序——
这一结构性劣势是比较的一部分,不做补偿。

### 时间前推(2002–2018 拟合 → 2019–2024 预测)

排名分位,0.5 = 随机,越小越好:

| 模型 | 市级(备择中位 13) | 县级(备择中位 103) |
|---|---|---|
| 条件 logit (M3) | 0.348 | 0.229 |
| 随机森林(默认) | **0.345** | **0.223** |
| 随机森林(类平衡) | 0.348 | **0.211** |
| 基线:随机 | 0.512 | 0.520 |

**打平。** 县级随机森林的 top-1 命中甚至略高(19.3% vs 16.1%)。

### 留一省(把整个省移出训练集)

| 模型 | 市级排名分位 | 市级 top-1 | 县级排名分位 | 县级 top-1 |
|---|---|---|---|---|
| **条件 logit (M3)** | **0.324** | **24.5%** | **0.278** | **10.4%** |
| 随机森林(默认) | 0.397 | 15.2% | 0.339 | 6.8% |
| 随机森林(类平衡) | 0.373 | 16.0% | 0.305 | 8.4% |

**机制模型明显胜出**,top-1 命中率高出六成以上。这才是把布点推广到新地区时的真实处境。

### 为什么会这样:两族模型看重的东西不一样

县级相对重要性(各自归一到最大值):

| 变量 | 随机森林 | 条件 logit |
|---|---|---|
| 已在分布区内 | 0.230 | **1.000** |
| 到分布区距离 | 0.405 | **0.760** |
| 年均温 | **1.000** | 0.354 |
| 海拔 | **0.750** | 0.096 |
| 年降水 | **0.773** | 0.199 |
| 单元面积 | 0.501 | 0.297 |
| 累计观鸟努力 | 0.213 | 0.296 |
| 保护地覆盖 | 0.337 | 0.109 |

条件 logit 靠**物种特异**的分布区距离;随机森林靠年均温、海拔、降水这些**通用地理描述**。
换句话说,随机森林学的是「哪些县一般容易出记录」,条件 logit 学的是
「哪个县离**这个物种**的分布区近」。前者在同一批省份里够用,换省就失效。

两族模型层内打分的 Spearman 相关只有 **0.494(市级)与 0.367(县级)**——
它们给出的排序确实很不一样。

## 三、结论与使用建议

1. **要外推,用机制模型。** 换省、换年份、换气候情景,随机森林都掉到基线附近,
   而且它的饱和行为是算法产物,不可解释也不可审查。
2. **要在已有格局内挑热点,随机森林可以用,但只能用来排序。** 它的概率不可直接使用
   (压扁或放大约 40 倍),必须先做等距校准或只取名次。
3. **随机森林的重要性排序本身是一个有用的诊断**:它把年份放在第一位,
   等于独立复现了本文的主论点——新纪录数据里最强的信号是观测过程。
   这可以作为「为什么必须显式建模观测过程」的一个旁证。
4. **不要用随机 CV 汇报这类数据的预测能力。** 随机 5 折下随机森林的 PR-AUC 是
   留省验证下的 2.6 倍;只报前者会严重高估可推广性。

## 四、必须一并陈述的局限

1. **offset 的不对称**:主模型把报告完整度作为系数固定为 1 的偏移项,
   随机森林只能把它当普通特征。这一不对称对随机森林有利(它可以自由加权),
   因此上述比较对机制模型是偏保守的。
2. **随机效应无法被树模型表示**:主模型最大的方差成分是省 × 年随机截距(SD 0.804),
   随机森林只能用省份与年份两个特征近似,无法表示两者的交互层级。
3. **时间前推下两族都很弱**:机制模型 AUC 0.524、随机森林 0.605,均接近随机。
   本文不宣称任何一族能可靠预测未来年份的具体发生,只比较相对表现。
4. **类平衡森林的 Brier 不可比**:下采样改变了先验,其 Brier(约 0.15)与
   其他模型(约 0.0037)不在同一尺度上,只能看斜率与排序。
5. **超参数未做系统搜索**:随机森林用 500–800 棵树、min.node.size 3–20 的常规设定。
   调参可能提升内插表现,但不会改变外推时的饱和行为,因为那是树模型的结构性质。
6. 本模块不替代已有的 XGBoost 对照(脚本 141 / Fig. M2–M4),两者结论方向一致:
   树模型在观测范围内与机制模型吻合,一出范围就分道扬镳。

```bash
Rscript code/180_rf_vs_hazard_province.R   # 省级:四套验证 + 校准 + 重要性 + 外推曲线
Rscript code/181_rf_vs_clogit_units.R      # 市县级:分配任务的两族对比
Rscript code/182_rf_figures.R              # FigR1–FigR2
```

需 `RENV_CONFIG_AUTOLOADER_ENABLED=FALSE`。省级脚本约 24 分钟(20 次 glmmTMB 拟合)。
产出:`analysis_v2/tables/tbl_rf_*.csv`、`analysis_v2/data/rf_extrapolation_curve.csv`、
`analysis_v2/figures_rf/`。
